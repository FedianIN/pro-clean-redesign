# Pro Clean: redesign concept

A static, single-page redesign of [pro-clean.es](https://pro-clean.es/) built for GitHub Pages.

- Plain HTML, CSS and JS, no build step
- Manrope font, Phosphor icons, flat backgrounds, Tailwind type and spacing scale
- Real content, photos and Google reviews taken from the current site
- Quote form that opens WhatsApp with a prefilled request (nothing is stored)
- `HouseCleaningService` structured data for local SEO
- `noindex` while it is a concept, so it does not compete with the live site

Run locally:

```bash
python -m http.server 8781
```
